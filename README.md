# Chinese-Children-Lexical-Association-Project-CCLAP-
This folder contains the analysis code and compact data files for the CCLAP manuscript.
The full association data and de-identified child demographic information are available at https://www.cclap-dataset.com/.

## Files
- `CCLAP_analysis.ipynb`: reproducible analysis notebook.
- `data/cclap_child_association_public.csv`: de-identified child association responses, including raw response text, segmented tokens/POS, and retained cleaned tokens/POS.
- `data/analysis_relation_strengths.csv`: derived cue-response or word-pair strengths for child associations, adult associations, child-directed speech, and child-directed books, restricted to analysis-relevant cues/word pairs.
- `data/analysis_word_measures.csv`: derived word-level measures used in the analyses, including child production frequency, speech/book frequency and contextual diversity, and WordBank AoA where available.
- `outputs/`: figures and aggregate result tables.
